<a id="tc-report-matrix"></a>
## 测试矩阵

### [REPORT-1] 有风控词表

- 场景：有风控词表
- 预期：短信/优先包用工程内表，不是上报时拉字典

### [REPORT-2] 短信词表为空

- 场景：短信词表为空
- 预期：`o_smsItems` 为空数组

### [REPORT-2.1] 词 `banco`，正文含 `abcbanco` 或 `abc_banco`

- 场景：词 `banco`，正文含 `abcbanco` 或 `abc_banco`
- 预期：不收录

### [REPORT-2.2] 词 `banco`，正文 `one Banco three`

- 场景：词 `banco`，正文 `one Banco three`
- 预期：收录；`o_body` 仍是原文大小写

### [REPORT-2.3] 词 `no reconoces`，正文 `no yes reconoces` 或 `noreconoces`

- 场景：词 `no reconoces`，正文 `no yes reconoces` 或 `noreconoces`
- 预期：不收录

### [REPORT-2.4] 词 `no reconoces`，正文 `one no reconoces three`

- 场景：词 `no reconoces`，正文 `one no reconoces three`
- 预期：收录

### [REPORT-2.5] 词 `g&t continental`，正文 `gt continental de su`

- 场景：词 `g&t continental`，正文 `gt continental de su`
- 预期：不收录

### [REPORT-2.6] 词 `g&t continental`，正文 `g&t continental de su`

- 场景：词 `g&t continental`，正文 `g&t continental de su`
- 预期：收录

### [REPORT-2.7] 词 `pagaré`，正文 `pagaré` 或 `pagare`

- 场景：词 `pagaré`，正文 `pagaré` 或 `pagare`
- 预期：收录；`o_body` 保持该条原文

### [REPORT-2.8] 词 `abc`，正文 `abc.`

- 场景：词 `abc`，正文 `abc.`
- 预期：收录

### [REPORT-3] applist 优先包名为空

- 场景：applist 优先包名为空
- 预期：无优先包，仅启动器补足（条数仍不超过风控给定上限）

### [REPORT-4] 短信 date

- 场景：短信 date
- 预期：毫秒；`o_addTime` / `o_uTime` 是秒；根 `o_uploadTime` 是秒

### [REPORT-5] 模拟器/SIM/root

- 场景：模拟器/SIM/root
- 预期：JSON 里是 0/1 数字

### [REPORT-6] 陀螺仪 xyz

- 场景：陀螺仪 xyz
- 预期：字符串

### [REPORT-6.1] 以太网/VPN 联网

- 场景：以太网/VPN 联网
- 预期：`o_netType` 是 `Cellular`，不是 `Unknown`

### [REPORT-6.2] 坐标

- 场景：坐标
- 预期：`经度,纬度` 顺序，单字符串

### [REPORT-6.3] 时区

- 场景：时区
- 预期：`短名,id`，一个逗号

### [REPORT-6.4] 相机 level

- 场景：相机 level
- 预期：小写枚举词，不是数字

### [REPORT-6.5] 陀螺仪 z

- 场景：陀螺仪 z
- 预期：必须是 `values[2]`

### [REPORT-6.6] `o_inb` / `o_outb`

- 场景：`o_inb` / `o_outb`
- 预期：`o_inb`=发件箱条数；`o_outb`=收件箱条数

### [REPORT-6.7] 设备 DTO

- 场景：设备 DTO
- 预期：有 `o_preview_sdk_int` 和 `o_sdk_int`；**没有** `system`

### [REPORT-6.8] 内部存储

- 场景：内部存储
- 预期：JSON string，两位小数 GB

### [REPORT-7] 请求 body

- 场景：请求 body
- 预期：只有加密 `data`，无明文 applist

### [REPORT-8] XOR

- 场景：XOR
- 预期：用工程内后台提供的偏移；明文 JSON 可逆校验

### [REPORT-9] 禁采项

- 场景：禁采项
- 预期：明文 JSON 里没有 §2.6 表中任何一项对应的 key；代码路径也不读 `Build.FINGERPRINT`

- 场景：隐私页同意 + 权限说明页同意
- 预期：进度=1；下次冷启直达首页

### [COMM-001-5] 权限说明页不同意（冷启动）

- 场景：权限说明页不同意（冷启动）
- 预期：进度=0；仍进首页

### [COMM-001-6] 隐私页 / 权限说明页按返回键

- 场景：隐私页 / 权限说明页按返回键
- 预期：无退出

### [COMM-001-10] 闪屏 / 隐私页 / 权限说明页

- 场景：闪屏 / 隐私页 / 权限说明页
- 预期：**不出现**系统短信/定位权限弹框
