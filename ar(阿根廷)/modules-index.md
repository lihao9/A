## Agent 执行约定

细则以 [`AGENT实现约定.md`](./AGENT实现约定.md) 为准，此处只列入口：

1. **唯一依据**：本目录模块文档 + `00` + 实现约定；缺信息则标 TBD / 问使用者，不要翻外部仓库。  
2. **对照稿 ≠ 实现稿**：梳理时看过的功能对照 UI 不算已提供实现链接；空表按 [`UI链接扫描规则.md`](./UI链接扫描规则.md) 重新要链接、确认后再填。  
3. **业务写死、外观/文案当变量**：状态码与去向在模块正文；颜色、字重、按钮文案进该模块元素表 / 视觉变量表，换链接只改表。  
4. 布局默认：顶栏固定、内容可滑、底栏吸底；有确认稿以稿为准。  
5. 切图：链接确认后按稿密度导出（常见 3x）；目录跟本工程。  
6. 接口：`ori` / `o_xxx` → 本包 API 文档；未指定 API 路径前不臆造 wire 名。  
7. 符号：类名/路由/包路径按本工程风格；**有壳跟壳**，正文不规定 UI 框架。  
8. 后续新模块按实现约定 §11 梳理，必须带链接登记表、元素对照表、视觉变量表。  
9. **整包写代码**按 [`整包落地顺序.md`](./整包落地顺序.md) 分波次，未过总闸、未定稿模块不得开写。  
10. **收尾对勾**：有字段表/规则表/测试表时按 [`AGENT实现约定.md`](./AGENT实现约定.md) §12.7 逐行对勾；有「未做」禁止称完整版；禁止空占位冒充已采集。
