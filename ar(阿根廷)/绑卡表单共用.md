# 绑卡表单共用（AR）

> 授信整页绑卡、账户「新增银行卡」弹层、借款确认里添卡，**中间表单与绑定请求同一套**。  
> 账户列表新增弹层壳见 [`05-绑卡.md`](./05-绑卡.md)；壳不同则只写壳，**不要再抄一份字段/校验/接口**。  
> 唯一依据：本文 + [`00-基础信息清单.md`](./00-基础信息清单.md) + [`AGENT实现约定.md`](./AGENT实现约定.md)。  
> 元素前缀：`BK-`。实现符号自定，不要求同名。

## 1. 只读头（展示）

宿主传入**明文姓名**和**证件号**（可已掩码）。

| 元素 ID | 内容 | 规则 |
|---------|------|------|
| `BK-TEXT-HOLDER` | 姓名 | 空则回退会话展示名 |
| `BK-TEXT-DNI` | 掩码 DNI | 已含 `*` 则原样；否则掩中间两位（8 位形如 `123**678`）。空则回退会话已掩码证件号 |

说明整段跟实现用 UI。业务：账号须是该人名下。

## 2. 字段与显隐

账户类型字典 type=`43`（以本包 API 为准），参考 key：CBU=`1`、CVU=`2`、Alias=`3`。

| 元素 ID | 字段 | 规则 |
|---------|------|------|
| `BK-SELECT-ACCOUNT-TYPE` | 账户类型 | 必选；点开再拉字典 |
| `BK-SELECT-BANK-NAME` | 银行 / PSP | **选完类型后才展示**；必选 |
| `BK-INPUT-ACCOUNT` | 银行账户输入 | 必填；标题固定，不随类型改成 Alias |
| `BK-INPUT-ACCOUNT-CONFIRM` | 银行账户确认输入 | 必填；**有标题**；与上一格 trim 后完全一致 |

### 2.1 给 UI 的标题 / hint（三种类型同一套）

| 位置 | 中文 | 建议西语（可改） | 旧稿不要再用 |
|------|------|------------------|--------------|
| 账户类型 · 标题 | 账户类型 | Tipo de cuenta | Elige tu tipo de cuenta |
| 账户类型 · hint | — | Selecciona tu tipo de cuenta | Seleccione tu tipo de cuenta |
| 银行账户输入 · 标题 | 银行账户输入 | Cuenta bancaria | Número de cuenta bancaria **或** Alias |
| 银行账户输入 · hint | — | Ingresa tu cuenta bancaria | Ingresa su cuenta bancaria **或** Ingrese su Alias |
| 银行账户确认输入 · 标题 | 银行账户确认输入 | Confirmación de cuenta | 旧稿无标题，需补 |
| 银行账户确认输入 · hint | — | Confirma tu cuenta bancaria | Confirma su cuenta bancaria **或** Confirmá tu Alias |

银行/PSP 选择器**不要打平**：CVU 用 PSP 语义，CBU/Alias 用银行语义。

切换账户类型：清空银行、两格输入及错误。未选类型时「银行账户输入」仍可打字，按 CBU/CVU 数字规则过滤。

## 3. 银行列表

- 进入表单拉 `ori: /bank/list`（可全量一次，前端按类型过滤）。
- 项带支持类型列表则只保留包含当前类型 key 的项；列表空或字段空视为该行支持全部类型。
- 无匹配时弹层为空列表，不得回落未过滤全量。
- 选中项可展示银行图标；图标失败不影响提交。

---

## 4. 输入与校验

长度见 `00`：CBU/CVU 6～22；Alias 6～22。

| 类型 | 过滤 | 键盘 | 格式 |
|------|------|------|------|
| CBU / CVU | 只留数字，截到最长 | 数字 | 长度不在 6～22 |
| Alias | 只留 `A–Z a–z 0–9 . -`，截到最长 | 文本 | 长度不在 6～22；不另做整段正则 |

提交时同时校验，有错滚到首错，不调绑卡接口。空文案 = 普通必填模板 + 字段标题。

| 规则 ID | 条件 | 挂点 |
|---------|------|------|
| `BK-VAL-TYPE-REQUIRED` | 未选类型 | 账户类型 |
| `BK-VAL-NAME-REQUIRED` | 未选银行 | 银行 |
| `BK-VAL-ACCOUNT-EMPTY` | 银行账户输入为空 | 银行账户输入 |
| `BK-VAL-ACCOUNT-FORMAT` | 有值但长度不符当前类型 | 银行账户输入 |
| `BK-VAL-CONFIRM-EMPTY` | 确认输入为空 | 银行账户确认输入 |
| `BK-VAL-ACCOUNT-MISMATCH` | 两格 trim 后不同 | 银行账户确认输入 |
| `BK-VAL-CONFIRM-FORMAT` | 两格相同但确认格长度仍不符 | 银行账户确认输入 |

### 4.1 错误文案（待确认西语）

> **特殊错误定义与 UI 清单：** [`特殊错误-UI定义.md`](./特殊错误-UI定义.md)。  
> 下表中格式 / 两次不一致为特殊错误；「请选择账户类型 / 请选择银行」走普通必填模板。

| 文案 ID | 中文语义 | 使用处 |
|---------|----------|--------|
| `BK-ERR-ACCOUNT-FORMAT` | 银行账户格式不正确 | CBU/CVU |
| `BK-ERR-ALIAS-FORMAT` | 银行账户格式不正确（Alias 长度） | Alias |
| `BK-ERR-ACCOUNT-MISMATCH` | 两次输入不一致 | 确认格 |
| `BK-ERR-TYPE-REQUIRED` | 请选择账户类型 | 可走必填选择模板 |
| `BK-ERR-NAME-REQUIRED` | 请选择银行 | 可走必填选择模板 |

## 5. 绑卡请求（共用）

### 5.1 银行列表 `ori: /bank/list`

请求（只传）：

| wire（语义） | 必传 | 来源 |
|--------------|------|------|
| `o_userId` | 是 | 会话 |

**不上送其它字段。** 过滤规则见 §3。

### 5.2 绑定 `ori: /bankcard/bind`

> 下表 = 上送白名单。**不送**银行 GID / `o_bankId`、确认格、活体/证件图 URL。

| wire（语义） | 必传 | 来源 |
|--------------|------|------|
| `o_userId` | 是 | 会话 |
| `o_accountType` | 是 | 账户类型字典 key |
| `o_bankName` | 是 | 所选银行名称 |
| `o_bankCode` | 是 | 所选银行 code |
| `o_accountNo` | 是 | 「银行账户输入」trim（CBU/CVU/Alias 均写入本字段） |

成功：接口成功且 `o_isBindSuccess == true`。布尔为 false/空：留在当前壳，**不**走宿主成功回调。网络/业务失败按全局错误，仍留当前壳。

若本包 API 强制 bankId，改本文后再实现。

## 6. 宿主接法（后面做弹层时照此核对）

1. 表单、弹层、校验、请求 **直接用本文**，发现与本文不一致先停、问使用者，不要默默再写一套。
2. 注入姓名/证件号；授信来源见 04，账户/借款页用来源页自己的展示名和证件号。
3. 成功回调：授信 → 04 §9 刷新授信；账户弹层 → 05 关弹层并重拉列表；借款弹层 → 06 关弹层、重拉列表并按 06 §6.2 选中。
4. 主按钮：`BK-BTN-SUBMIT`；西语由宿主 UI 定（授信与弹层可以不同）。
5. 不落绑卡草稿，除非某宿主文档单独写。
